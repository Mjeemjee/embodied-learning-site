矩阵运算过程

基础变换 (Base Transforms)

旋转矩阵 Rot(θ)

[ cos(θ) -sin(θ)  0 ]
[ sin(θ)  cos(θ)  0 ]
[   0       0     1 ]

平移矩阵 Trans(x, y)

[ 1  0  x ]
[ 0  1  y ]
[ 0  0  1 ]

连杆变换矩阵构建 (T = Trans × Rot)

连杆1的变换: T₀¹ = Trans(L₁c₁, L₁s₁) × Rot(θ₁)

连杆2的变换: T₁² = Trans(L₂c₂, L₂s₂) × Rot(θ₂)

最终连乘与结果提取: T₀² = T₀¹ × T₁²
